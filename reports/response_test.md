def quicksort(arr):
    # 基准情况：如果列表包含 0 或 1 个元素，则它已经是有序的
    if len(arr) <= 1:
        return arr

```python
def quick_sort(arr):
    # 리스트의 요소가 1개 이하이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(Pivot) 설정: 리스트의 중간 요소를 선택
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 정렬하고 합침
    return quick_sort(left) + middle + quick_sort(right)

# 테스트 코드
if __name__ == "__main__":
    test_list = [3, 6, 8, 10, 1, 2, 1]
    print(f"정렬 전: {test_list}")
    
    sorted_list = quick_sort(test_list)
    print(f"정렬 후: {sorted_list}")
```

### 코드 설명:
1.  **기저 사례 (Base Case):** 리스트의 길이가 0 또는 1이면 정렬이 필요 없으므로 바로 반환합니다.
2.  **피벗 선택 (Pivot Selection):** 여기서는 리스트의 중간 인덱스 값을 피벗으로 잡았습니다.
3.  **분할 (Partitioning):**
    *   `left`: 피벗보다 작은 값들을 모은 리스트
    *   `middle`: 피벗과 같은 값들을 모은 리스트
    *   `right`: 피벗보다 큰 값들을 모은 리스트
4.  **재귀 (Recursion):** `left`와 `right` 리스트에 대해 다시 `quick_sort` 함수를 호출하여 정렬을 진행하고, 최종적으로 `left + middle + right`를 합쳐 결과를 만듭니다.

```python
def quick_sort(arr):
    # リストの要素が1つ以下なら、そのまま返す（ベースケース）
    if len(arr) <= 1:
        return arr
    
    # ピボット（基準値）をリストの中央の要素に設定
    pivot = arr[len(arr) // 2]
    
    # ピボットより小さい要素、等しい要素、大きい要素に分割
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    # 再帰的にソートして結合
    return quick_sort(left) + middle + quick_sort(right)

# テスト用のデータ
data = [3, 6, 8, 10, 1, 2, 1]
print(f"元のデータ: {data}")

sorted_data = quick_sort(data)
print(f"ソート後: {sorted_data}")
```

### 解説：
1.  **分割統治法（Divide and Conquer）**: クイックソートは、リストを「ピボットより小さいグループ」「ピボットと同じグループ」「ピボットより大きいグループ」に分割し、それぞれのグループに対して同じ処理を再帰的に適用します。
2.  **ベースケース**: リストの長さが1以下になったら、それ以上分割できないため、そのまま返します。
3.  **計算量**: 
    *   **平均的な時間計算量**: $O(n \log n)$
    *   **最悪の時間計算量**: $O(n^2)$ （ピボットの選び方が極端に悪い場合）
4.  **空間計算量**: この実装はリスト内包表記を使っているため、新しいリストを作成するためメモリを消費しますが、コードが非常に読みやすいというメリットがあります。
